# 飞书 Slides 适配

## 证据范围

下述页面选择器与失败经验来自既往飞书 Slides 截图操作；Chrome 的接入、PNG 编码与设备倍率已做局部验证，但完整翻页流程仍需在目标文档验收。选择器、缩放数值和错误码作为排障线索，不代表所有账号、文稿和版本的固定行为。

## 定位与缩放

先检查当前 DOM。旧记录中的定位线索：

| 对象 | 选择器／线索 |
|---|---|
| 缩放输入框 | `input.ud__native-input`，位于右上角 Comment 附近 |
| 当前主画布 | `.slide-canvas`，当时只有一个 |
| 左侧目录滚动容器 | `.slide-catalogue-container` |
| 目录项 | `.slide-item-full-wrapper`，文本以页码开头 |

旧记录中缩放框未出现在无障碍树，搜索 `160%` 文本也未命中。若当前仍如此，观察 DOM 确认输入框，再用当前浏览器提供的输入方法：

```js
const zoom = tab.playwright.locator("input.ud__native-input");
// 先确认唯一性及其确为画布缩放框；多个匹配时按当前 DOM 缩小范围
await zoom.click();
await zoom.fill("200");
await zoom.press("Enter");
```

原文稿在 2560×1440 视口、200% 画布缩放下，CSS 画布为 1920×1080，并完整落在视口内。160% 时约为 1536×864，仅扩大窗口没有提高画布尺寸。400% 时约为 3840×2160，出现负的画布原点，单次可视区域截图会切边。这些是该版页面／文稿的观察值，不能替代当前测量。

若 200% 下无法完整容纳画布，先确认实际视口、Chrome 页面缩放和 UI 面板占用；不要直接把负坐标截取结果当作完整页。分块拼接属于另行评估的扩展，不是本技能默认路径。

## 翻页

按准确页码选目录项，避免“1”同时匹配“10”。目录可能虚拟化，当前 DOM 项数不一定是总页数。滚动容器使目标项真正可见，再重新获取矩形。

旧记录用目录项内部 `x + 130`、`y + height/2` 的页面坐标点击成功；这个偏移只是一条线索。当前应选择缩略图内容内部的可见安全点，避开菜单、拖动柄和页码之外的控件。点位要同时落在视口与目录可见区域内。

旧记录中的元素 `click()` 没有换主画布；记录不足以证明所有高层 locator 点击都会失败。优先使用当前工具支持的 UI 点击，若选中态未变化，再依据新状态调整点击方式。禁止使用只读 DOM evaluate 实现点击或滚动。

切页后验证选中页码／当前页标识，并读取画布前约 24 字或查看画面辅助核对。650ms 是旧记录的经验等待值；页面加载较慢时，以渲染完成为准。空白页、纯图片页或连续相同页无法依赖文本区分，必须有页码／页标识证据。

连续的结束页可能内容相同，仍须按原始页码全部保留，不能据此执行图像去重。

## 避免重复的失败尝试

以下是同一次历史操作的结果，不是当前所有文档的永久限制。对同一任务已有这些证据时直接使用浏览器路径；换文档、账号或产品版本后，才按实际需求重新核查。

| 旧路径 | 当时结果 | 对后续的影响 |
|---|---|---|
| `lark-cli drive +export` 导出 PDF／PPTX | `1069902` | 当时可查看但无法整份导出；不反复提交相同请求 |
| `lark-cli drive +preview` | 在线 Slides 类型不匹配 | 不当作在线幻灯片通用预览入口 |
| `lark-cli slides +screenshot` | 补齐 `slides:presentation:screenshot` 后，接口返回非零页数、图片列表为空 | 获得 scope 不代表有完整结果；本技能不为试通接口自动扩大授权 |
| `slides_ai/v1/slide_image/render` | 当时固定输出 960×540 PNG，schema 未提供 scale／dpi／quality；连续调用触发 `99991400` | 不以此保证高清整本输出，不编造放大参数，不连续重试限流 |
| 只下载每页中的单张 `file_token` | 多数页由文字和形状构成，单图不含完整正文 | 使用完整渲染后的画布 |
| Present／`requestFullscreen()` | 当时没有进入播放页 | 不把演示模式作为截图前置条件 |

以上 API 名称用于解释历史排障证据；需要重新检查官方能力时使用现有 CLI 与当前官方说明，不按本表拼直接 HTTP 调用。
