# 消息、会议与协作能力地图

按用户目的选择领域，不因出现“待办”“会议”“联系人”就默认同一工具。此概览按本地 `lark-cli 1.0.97` 官方说明核对；执行时按 [官方导航规则](official-suite-navigation.md) 读目标指南、参考与当前 help。能力介绍不授权读取私人数据、发送消息、入会或修改资源。

## 即时通讯 — `lark-im`

- **能力与触发：**发消息/回复，搜索聊天和消息，读取历史/线程，查看管理群成员，图片文件上传下载，卡片、回调、表情、加急、标签及 Feed 置顶。“给某人回复”“找昨天的消息”“处理卡片点击”从这里进入。
- **边界：**发消息不等于发邮件；搜索聊天不等于遍历通讯录；持续事件消费参考 `lark-event`。身份与可见范围由实际命令决定，不自动在 user/bot 间切换。
- **Next 增量：**完整时间范围归档、分页/线程/资源证据留存选 `$feishu-next:feishu-im-chat-archive`。只查一条消息或发一条回复直接用官方方法。归档完成不自动授权发送归档。

## 飞书邮箱 — `lark-mail`

- **能力与触发：**读取搜索邮件，起草、发送、回复和转发，文件夹、标签、邮件联系人、收信规则与新邮件监听。“起草邮件”“找附件邮件”用 Mail。
- **边界：**邮件联系人与企业通讯录不是一回事；普通 IM 消息不用 Mail。
- **Next 增量：**暂无专属邮箱玩法；只有任务还包含 Next 导出/归档等产物时才由 Router 衔接。写草稿不自动发送。

## 日历与会议室 — `lark-calendar`

- **能力与触发：**查询搜索日程，创建更新会议安排，参会人、忙闲、推荐时段和会议室。“约个会”“今天安排”“找空闲会议室”用 Calendar。
- **边界：**过去或正在进行的会议发言、纪要和妙记属于 Meeting；普通待办属于 Task。相对日期必须使用调用方/用户时区证据。
- **Next 增量：**暂无专属排会玩法；先复用官方方法，不因排会本身有多步就新增 Next 技能。

## 视频会议与会议产物 — `lark-meeting`

- **能力与触发：**会议记录、纪要、逐字稿、妙记的查询和相关处理；正在进行的会议内容问答、智能体参与、会中消息/表情按官方支持范围执行。“整理会议发言”“查妙记”“会上说了什么”从这里进入。
- **边界：**预约、忙闲和会议室走 Calendar；入会/离会及会中发送有副作用，不能从读取意图推导授权。缺少一种会议产物不证明所有内容都不存在。
- **兼容名称：**`lark-minutes`、`lark-note`、`lark-vc`、`lark-vc-agent` 在当前官方分流到 `lark-meeting`，不是四项新的独立能力；旧发行版按实际 runtime 核对。
- **Next 增量：**先检查官方会议汇总工作流。需要与聊天证据、导出等其他步骤结合时，Next 才保留外层任务状态。

## 任务 — `lark-task`

- **能力与触发：**待办、任务清单、子任务、成员、附件及任务智能体。“建待办”“拆分子任务”“更新完成状态”用 Task。
- **边界：**审批待办走 Approval，会议时间走 Calendar，OKR 走 OKR。用户说“总结行动项”不等于授权创建远程任务。
- **Next 增量：**暂无专属任务管理玩法；与归档/文档结合时，在完成证据明确后按授权衔接，不自动分配人员。

## 审批 — `lark-approval`

- **能力与触发：**查询处理审批待办/已办/实例，搜索审批定义、读详情、发起原生审批实例。“审批进度”“发起这类审批”从这里进入。
- **边界：**不是普通任务，也不是创建审批定义；三方审批不套原生提单。处理/提交审批需确认精确对象和内容。
- **Next 增量：**无专属提单玩法；使用官方流程，不从业务文档自动推断应提交哪种审批。

## 联系人、考勤、OKR

- `lark-contact`：按姓名/邮箱解析身份，按 ID 查看可见资料，搜索可见机器人/智能体；不是部门树遍历或全组织导出工具。多候选时先消歧，再交给 IM/Calendar，不能猜第一个人。
- `lark-attendance`：查询自己的考勤打卡记录，不把这一能力扩大为替人打卡或管理员修改考勤。
- `lark-okr`：周期、目标、关键结果、对齐、量化指标和进展；不等于绩效评价，也不代替 Task。
- 这些领域暂无专属 Next 玩法，直接使用相应官方指南；仅按当前请求接入外层工作流。

## 官方已提供的组合流程

- `lark-workflow-meeting-summary`：按时间范围汇总会议纪要和产物，生成结构化报告；是否生成/写入远程文档按用户请求和官方步骤决定。
- `lark-workflow-standup-report`：合并日程与未完成任务，给出今日、明日或指定范围的安排摘要。

精确匹配时直接复用官方工作流，不因为它已经包含多个领域就重复包装。若只是较大 Next 任务中的一段，把其真实输出与未完成事项带回外层流程。
