# 文档格式修复 playbook

仅在处理标题错位、材料边界或粘贴残留时读取对应段落。按[本技能正文](../SKILL.md#编辑与回读)建立基线、执行写入和异常恢复；下文描述修复判断与变换。

## 1. 只读诊断

从完整快照清点标题层级、编号、文本节点、资源与链接，结合上下文确认症状。单份复制或导入内容与多份拼接材料均可检查；出现同样的字词或编号只是候选线索。

需要字数或块类型画像时，读取当前 `lark-doc/references/lark-doc-script.md`，可对从基线 `content` 提取的 XML 使用 `docs +script --command parse --content @./snapshot.xml`。检查 `data.assessment.status` 和 diagnostics，并按本技能正文继续做独立的语法与保真核验。

## 2. 材料边界判定信号

- 交叉核对材料题名、开场句、章节编号重启和内容主题变化。编号重复可能是多份独立材料的正常起号，不能单独据此删重或重编号。
- “已完成报告”“下面按照”等句子可提示会话边界，也可能属于正文；拟删除的具体句子列入方案，沿用用户已确定的清理范围。
- CSS 残段与图形文字的边界逐块识别，不假定固定字符数或正文只位于尾部。保留可辨认的节点、分支标签与来源线索。
- 链接参数不作为格式残留删除，保留原始目标。

## 3. markdown 导出的假象

Markdown 导出用 `**bold**` 表达加粗，也可能把原有星号转义。回到 XML 检查实际文本节点与行内标签，不靠导出的反斜杠数量判定。检查段落、列表和嵌套容器中的文本；代码、公式或刻意展示语法的内容保持原样。

## 4. 标题层级与编号

- 先确定标题属于哪份材料及哪个父级，再改变必要的标签或属性。只需应用明确标题级别规则时由 align 处理；恢复错误归属时保留用户确定的材料结构。
- 保留自动编号方式与列表起始编号。目标层级无法保留原编号时先列明差异，按已确认方案处理；只有用户要求保留显示编号且允许写入正文时才固化编号，避免与自动编号重复。
- 一次完成同一块的层级、编号和标记调整，写前按本技能正文检查父容器约束与全部允许差异。

## 5. 字面 `**` → 真加粗

先确认哪些文本区间的星号是误粘贴的加粗标记；代码、公式、链接属性和有意保留的星号不参与转换。成对标记只说明候选区间，不足以证明可以安全转换。

在解析后的 XML 文本节点上定位标记。单节点内配对时拆分文本并包裹 `<b>`；跨行内节点时，保留原有标签嵌套，分别为命中的文本片段加粗，不让新标签跨越原标签边界。例如：

```xml
<p><span>**重要</span><span>正文**</span></p>
```

在该区间已确认需要转换时，可生成：

```xml
<p><span><b>重要</b></span><span><b>正文</b></span></p>
```

跨块、未配对或无法保留嵌套结构的情况先保留并列明。写前重新解析生成的 XML，核对正文仅删除了指定标记，原有属性、链接目标、换行与样式仍在；禁止对原始 XML 字符串全局正则替换。

## 6. mermaid CSS 残段重建

- 先区分 CSS、原图源码和可见文字；从可用源码、原图或上下文核对节点、连线方向及分支标签，不凭节点文字猜关系。
- 信息足够且符合用户选择与全文风格时，可恢复为 ASCII 树、代码或图形。ASCII 形式使用 `<pre lang="plain"><code>…</code></pre>`，保留已验证的节点与分支；需要画板时按 Router 选择相应能力并读取当前 `lark-doc` 画板工作流，更新已有画板复用其 token。
- 只有节点文字而缺少连线证据时，保留文字和顺序，在交付中列明缺失信息。只有 CSS 边界已确认且清理获准时才删除该部分；边界不清的块先保留。

## 7. 材料级标题

拟题依据取材料自身题名、引用文件名或开场句，并在方案中区分新增标题、层级调整和标题文字精简。多份独立草稿可以各挂材料级标题，是否合并由用户决定。

用户指定 H1 时保持 H1；仅授权调整层级时，标题原文保持不变。多句说明误作标题时，优先提出“短标题＋原段落”的方案；用户已允许精简或拆分时，才生成短标题，并把原说明逐字移入正文，保留链接和行内样式。标题层级和标题文字是两项不同的修改，不因标题长就擅自降级或改写。

补标题可用 `block_insert_after` 锚定当前前一块；标题拆分可在父容器支持时用一次 `block_replace` 写入标题和原段落。按本技能正文的写入与回读要求执行，并核对原文去向和相邻标题。

## 8. 修复结果核对

逐块保真检查完成后，再按问题清单核对：

- 标题归属和材料边界恢复到用户确定的结构，各材料内编号正确；独立材料允许重新起号。
- 标题增补、拆分、编号固化与标记清理逐项对应获准差异；拆分后的原段落完整且顺序正确。
- 已确认的损伤与残留完成处理；有意保留、证据不足和转换失败的项分别列明。代码、公式和有意展示的星号不作为未清理错误。
- 用户同时要求样式对齐时，仅在修复结果验收后交出最新快照、revision、块映射和遗留项；后续从该状态继续。
