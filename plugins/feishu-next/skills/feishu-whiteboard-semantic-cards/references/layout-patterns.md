# 按关系选择版式

| 材料主要关系 | 适合版式 | 设计重点 |
| --- | --- | --- |
| 对象并列、分类、能力清单 | 分组卡片 | 按相同字段比较，组内同级、组间留白 |
| 有触发、步骤、交付与反馈 | 流程图 | 先画主路径，再补分支和回流；卡片写动作 |
| 多个角色、阶段或存储位置共同参与 | 泳道 | 按读者追踪的对象划分泳道，跨泳道箭头说明交付 |
| 多对象按相同标准比较 | 矩阵 | 行列维度统一，空格注明含义；文字太长则拆成总表和细节 |
| 同一对象有前后差异 | 前后对照 | 按同一个问题对齐旧做法、新动作和实际变化 |
| 材料复杂、读者需先抓主线 | 总图＋分镜 | 总图展示结论和主要关系，分镜回答某个关键机制 |

## 分组卡片

分组先来自材料的分类，再决定几列。两级结构可用组标题＋卡片网格。卡片尽量回答相同问题，例如“做什么／何时／例子”；不适用的字段可省略或明确说明。

文字较多时用两列或上下排列；短内容可以三列或更多。不同组的项目数不必相等，可用 2×2、上下两张、两张加一张居中等结构保持清楚。

## 流程与泳道

先列对象和边，再安排几何位置，避免先画漂亮方框再猜关系。箭头通常从卡片边缘进入或离开；线和线交叉时优先调整布局。

主流程尽量沿同一方向阅读。回流绕到外围，标签说明何时或什么信息回来。纵向空间不够时拆分阶段，避免蛇形阅读承担过多折返。

读者关心职责时按角色划分，关心信息去向时按阶段或载体划分；其他属性可用标签补充。每条泳道的标题应说明其中放的是什么，跨泳道箭头标出交付的信息或动作。

例如三个角色共同完成六个步骤：需要看谁负责，可按角色设泳道、沿时间方向放步骤；只需要看六步怎么推进，则用流程图并在步骤上标执行者。两种画法服务的问题不同，先选阅读重点。

## 矩阵与前后对照

矩阵以可比较为先：同一行回答同一个问题，同一列保持相同对象。需要时用侧边色条区分类别，结果单独成行。与正文表格相比，画板矩阵只保留判断所需的短句。

前后对照避免两边各说各话。例如按“入口、判断依据、更新方式”逐项对齐；中间可放导致变化的动作。没有效果验证时标目标或预期，不配成已完成的绿色结果。

例如五个案例各有四项信息：用矩阵能快速横看差异，但完整段落会把单元格拉成长文。允许概括时，总览只保留各项判断与证据入口；需要逐案讲清机制时，再用案例卡或分镜展开。仅因案例摆在左右两边，不能加成先后流程。

## 总图与分镜

总图通常可以按“问题→关键做法→变化”组织；研究材料也可按“机制→实践→适用判断”组织。选择符合材料的主线，不把所有图固定成同一种叙事。

拆图依据是是否出现不同的阅读问题，不能只按段落数量拆分。用户要求一页时，优先在一页内组织主次；未经允许不增加一套分镜替代交付。

分镜回答总图中的一个问题，沿用对象名称、颜色与编号。可选共同导航条帮助定位；没有共同维度时用小节名或简短副标题即可。

## 设计交付时的说明

一句话说明本图如何读即可，例如“按列看三个参与者，按行看形成、取用和维护；虚线为人工反馈”。复杂图还可补充哪些细节已下沉到正文，避免在画布上叠加长图例。
