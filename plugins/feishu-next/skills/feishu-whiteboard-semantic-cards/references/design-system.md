# 视觉规范

这些数值是起点，用来维持一组图的共同秩序；按参考风格、内容和实际嵌入宽度调整。

沿用参考图时，先提取标题区、卡片构造、颜色含义和文字密度，再套到当前内容。只复用能解释当前关系的布局；参考中的分类数、案例数和流程顺序不自动成为新图要求。

## 语义色

先分配颜色含义，再画组件。同一组图保持相同映射；新主题可重新分配。

| 色系 | 主色 / 浅底 | 可用含义举例 |
| --- | --- | --- |
| 蓝 | `#2F63E6` / `#EDF2FF` | 总体说明、入口、基础机制 |
| 紫 | `#6E55C2` / `#F3EFFD` | 形成、生产、写入 |
| 青绿 | `#0F7C72` / `#E6F4F1` | 取用、执行、服务 |
| 橙 | `#D46B08` / `#FFF4E6` | 维护、回流、人工关注 |
| 红 | `#D83931` / `#FDEDEC` | 有证据的问题或风险 |
| 绿 | `#2EA121` / `#EEF8EC` | 已验证结果、完成状态 |
| 灰蓝 | `#3B4452` / `#F2F4F7` | 背景条件、存储、辅助说明 |

一张图以少量主色组织层级。彩色用于标题栏、边框、编号和关键数值；常规正文用 `#1F2329`，补充说明用 `#4E5969`。低对比的灰字仅放非关键来源等信息，需在预期尺寸下可读。

状态同时标文字、实心/空心、虚线或符号。给“未涉及”“未披露”“未完成”分别使用准确标签；缺少材料不能自动标成失败。

## 尺寸与字体

| 项目 | 建议起点 |
| --- | --- |
| 画布 | 宽 1200，左右边距 40，高度随内容增长 |
| 字体 | `Noto Sans SC, PingFang SC, sans-serif`，实际使用取决于渲染环境 |
| 主标题 | 32–36，粗体；旁边可配一条短竖色条 |
| 副标题 | 18–20，说明范围、对象或依据 |
| 模块标题 | 22–28，和正文拉开层级 |
| 正文 | 通常 20–22；密集矩阵约 17–20，需按嵌入宽度检查 |
| 辅助标签/来源 | 通常 14–18，长内容可移到正文 |
| 行距 | 字号的 1.35–1.5 倍 |
| 卡片 | 内边距 18–24，间隔 20–32，圆角约 12 |
| 边框/连线 | 边框约 1.4–1.8，主连线约 2–2.5 |

两列适合解释，三列适合并列对象，更多列适合短标签和轻量对照。以最宽正文或最高卡片计算布局，不把 1200 宽当成必须塞满的固定页。

## 按显示宽度检查

等比缩放时，显示字号约为 `源字号 × 显示宽度 / 源画布宽度`。例如 1200 宽的图以 720 宽显示，源稿 20 的正文只剩约 12。源稿放大看得清楚，仍需按最终嵌入宽度检查。

显示后太密，优先减少并列列数、调整内容层级或把细节移入获准的分镜/正文；原文必须保留时增加空间。固定一页和原文保留无法同时满足时，说明冲突并请用户决定取舍。

## 组件的职责

- **标题区**：标题表达本图主题或判断；副标题补范围和来源。读者需要时才加“分镜”等定位文字。
- **卡片**：标题是对象或动作，正文解释做法；触发、执行者或证据可用小标签区分。并列卡片按共同字段组织。
- **说明带**：放适用于整图的一句条件、结论或注意点。只覆盖局部的条件留在对应卡片。
- **效果块**：有可靠数值时可放大关键数字，附近保留指标、范围与来源；定性结果用具体变化表达。
- **连接器**：只表达真实顺序、依赖、交付或反馈。回流可用虚线或折线，并写动作。保持层级关系的图不必强加箭头。
- **导航条**：按共同维度定位本图。高亮项、灰色项及“人工”等标签应有定义；不要让读者将覆盖数量误读成成绩。

对齐看同级对象：卡片标题从同一基线开始，同行卡片按最长内容安排高度。连线避开文字，回流标签靠近对应线段。数字与文字都需要保留单位、范围和状态，视觉强调不能把预期变化改成已验证效果。

阴影是可选细节。飞书转换保真优先于装饰效果，默认组件不依赖滤镜。
